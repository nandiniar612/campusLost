# CampusLost 🎓🔍
> **Smart Lost and Found Portal for University Campuses**

CampusLost is a centralized, digital lost-and-found portal designed for college campuses. It streamlines reporting lost belongings, logging found items, and facilitating fast verifications and handoffs between students and campus administration.

---

## 📌 Problem Statement
On large university campuses, misplaced items often go unclaimed due to fragmented physical lost-and-found bins, scattered social media posts, and lack of real-time searchability. 

CampusLost solves this with:
- A unified campus registry for all lost and found items.
- Asynchronous cloud-persisted reporting with instant status feedback.
- Fast keyword search and category filtering.
- Dual-role workflows for students and campus staff.

---

## ✨ Key Features
- **Report Lost Belongings**: Submit item details, last known location, date, and description.
- **Report Found Items**: Log items found across campus buildings (library, cafeteria, classrooms, labs).
- **Interactive Search & Filter**: Real-time browsing by item type, location, and resolution status.
- **Live Status Tracking**: Immediate cloud synchronization tracking whether an item is *Open*, *Matching*, or *Claimed*.
- **Role Simulation**: Seamless switching between student views and campus administration views.

---

## 🛠️ Tech Stack & Architecture
- **Frontend**: TypeScript, Vite, Responsive Web Components
- **Persistence & Cloud**: Google AI Studio Cloud Datastore & Firestore Rules
- **State Management**: Reactive in-app async pipelines with optimistic UI updates
- **Version Control**: Git & GitHub
